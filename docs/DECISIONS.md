# Принятые решения

## 2026-10-30 — структура репозитория

По запросу владельца проекта исходники сгруппированы в пакет `facet` по назначению: HTTP, проекты, BPMN, аккаунты, ИИ, интеграции и desktop. Интерфейс перенесён в `frontend`, инструкции — в `docs`, конфигурация развёртывания — в `deploy`, CSS отчёта — в `resources`.

Причина: раньше серверные модули, инструкции и конфигурация лежали вместе в корне. Новая структура облегчает поиск компонентов и явно показывает зависимости.

Сохранены HTTP API, формат SQLite и три прежние команды запуска через небольшие совместимые файлы. Для приложения добавлен запуск `python3 -m facet`; ресурсы и локальный `.env` привязаны к корню проекта через `facet.paths`. Новые зависимости не добавляются. Команды Compose теперь требуют `-f deploy/compose.yaml`.

Работа выполняется в отдельной ветке репозитория портфолио. Исходная рабочая папка и production-сервер не изменяются. Ключи, пользовательские данные и журналы остаются вне Git. Известный сбой теста изображения в импортированной презентации воспроизводится до переноса и отмечен в описании проверки.
