# Facet

Общайтесь по-русски. Это чистая копия исходников для портфолио.
Не добавляйте в Git .env, ключи, токены, пользовательские базы, письма и журналы.
Храните только пустые примеры секретных переменных в .env.example.
Проверяйте Git перед изменениями, сохраняйте чужую работу.
Не запускайте полный набор тестов без прямой просьбы пользователя; проверяйте затронутый сценарий.
Production-сервер и его доступы в эту копию не входят.
