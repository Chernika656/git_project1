# Facet

Веб-MVP для совместного проектирования: процессы BPMN, UML-диаграммы, требования, презентации и HTML-прототипы в одном проекте.

Проект начинался как локальный анализатор BPMN и вырос в рабочую среду для аналитиков и команды. Эта копия подготовлена из последней локальной версии исходников для портфолио. Работа внешнего ИИ-провайдера и production-сервера при подготовке не проверялась.

## Возможности

- Проекты и доска связанных блоков.
- Редактор BPMN, импорт/экспорт XML, статическая проверка ошибок с подсветкой.
- UML sequence и детализация отдельных задач процесса.
- Требования и критерии приёмки, связанные с элементами схем.
- Аккаунты, командные пространства, приглашения и права доступа.
- Подготовка презентаций и экспорт проекта.
- ИИ-помощник для анализа проекта и генерации HTML-прототипов; изменения применяются после просмотра пользователем.

## Стек

Python 3.10+, SQLite, HTML/CSS, JavaScript и SVG. Сервер использует стандартную библиотеку Python; установка Python-зависимостей для веб-версии не требуется. Библиотеки для презентаций включены в `web/vendor` вместе с лицензиями.

## Локальный запуск

Из корня репозитория:

```sh
python3 web_app.py --port 8765 --data ./data/workspace.sqlite3
```

Откройте http://127.0.0.1:8765. Для остановки нажмите Ctrl+C. При первом запуске создаётся новая база; зарегистрируйте тестовый аккаунт. Без SMTP письма сохраняются локально в `data/mailbox` — подробности в [ACCOUNTS.md](ACCOUNTS.md).

API-ключ для запуска приложения не нужен. Для реальной генерации ИИ потребуется собственный ключ в локальном `.env`; используйте [.env.example](.env.example) и [инструкцию ИИ-помощника](AI-AGENT.md). Внешние сервисы в HTML-прототипах имитируются. Режим шаблона без ИИ не является ответом модели.

## Подготовка к публикации

В репозитории остаются только исходники, тесты, учебные примеры и конфигурационные шаблоны. Ключи, `.env`, SSH-доступы, пользовательские базы, письма, журналы, виртуальное окружение и настройки IDE исключены. Секретные поля в примерах окружения пустые.

При подготовке проверены запуск веб-сервера с чистой временной базой без API-ключа, ответ `200` от `/api/health` и загрузка главной страницы Facet. Файлы проверены на совпадения с локальными секретами и распространённые форматы ключей. Полный набор тестов в этой подготовке не запускался.
